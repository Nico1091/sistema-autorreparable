@startuml
skinparam style strictuml
skinparam sequenceMessageAlign center
skinparam shadowing false

title MBSE: Validación de Comportamiento Estructura de Evolucion - HU-OPS-01

' Definición de participantes con colores correspondientes
participant "Usuario\n(Front-End)" as User #LightBlue
participant "Orquestación\n(Control)" as Orq #LightGray
participant "Enjambre Operativo\n(Ejecución Real)" as Enjambre #LightGreen
database "LDB-OPS / GDB\n(Datos)" as DB #White
participant "Unidad de Salud\n(Monitoreo)" as Salud #LightYellow

== Escenario 1: Procesamiento exitoso de requerimiento lícito ==

note over User, Salud #AntiqueWhite
  **Dado que** el Enjambre está en espera
  **Y** la Orquestación recibe la firma **SNAKE-256**
end note

User -> Orq: Enviar Requerimiento Técnico
activate Orq

Orq -> Orq: **Cuando** se valida la firma autorizada

Orq -> Enjambre: Autorizar inicio de proceso real
activate Enjambre #LightGreen

Enjambre -> Enjambre: Ejecutar algoritmos de mercado

Enjambre -> DB: **Entonces** debe calcular Costo_Final_Real
Enjambre -> User: **Y** notificar resultados  
Enjambre -> DB: **Y** sincronizar estado final en GDB

deactivate Enjambre
deactivate Orq

== Escenario 2: Intento de ejecución sin autorización (Seguridad) ==

note over User, Salud #LavenderBlush
  **Dado que** ingresa un requerimiento externo al sistema
end note

User -> Orq: Enviar Requerimiento (Firma Inválida)
activate Orq

Orq -> Orq: **Cuando** el protocolo SNAKE-256 falla

Orq -> User: **Entonces** denegar acceso inmediatamente
Orq -> Salud: **Y** registrar alerta de intrusión
note right of Salud: Activación de Autorreparación

deactivate Orq

@enduml
